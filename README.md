# C# Learning

Training curriculum covering C# fundamentals, deep-dive language concepts, PostgreSQL, ASP.NET, and unit testing — building toward a backend capstone project.

## Structure

- `codecademy/` — exercises and projects from Codecademy's C# courses, one folder per topic
- `codecademy/deep-dive/` — Deep Dive track projects (numbered by topic, not sequential file order)
- `katas/` — Codewars kata solutions, one folder per kata
