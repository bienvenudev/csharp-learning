# Baseball DB — Off-Platform Project
Codecademy "Design Databases with PostgreSQL" project. Uses the Sean Lahman
baseball database (29 tables, 1871–2019) with PostgreSQL. Covers multi-table
JOINs, GROUP BY / aggregate functions (AVG, SUM, ROUND), and HAVING clauses
to hand out awards like Heaviest Hitters, Biggest Spenders, and Priciest
Starter.
